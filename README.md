# Cisco DHCP Configuration Lab

## 📌 Overview
This project demonstrates the configuration of a DHCP (Dynamic Host Configuration Protocol) server using Cisco Packet Tracer. The lab simulates a small network where devices automatically receive IP addresses from a DHCP server.

## 🎯 Objectives
- Automatically assign IP addresses to client devices
- Verify network connectivity
- Understand DHCP workflow in a LAN environment

## 🛠️ Tools & Technologies
- Cisco Packet Tracer
- Networking (DHCP, IP Addressing, Subnetting)

## 🧩 Network Topology
The network consists of:
- 1 Server 
- 1 Switch
- Multiple PCs (DHCP clients)

## ⚙️ Configuration Steps
1. Configure DHCP pool:
   - Define network and subnet mask
   - Set default gateway
   - Assign DNS server
2. Connect PCs and enable DHCP on clients
3. Verify IP assignment using `ipconfig`

## ✅ Verification
- Devices receive IP addresses automatically
- Successful ping between devices
- DHCP binding table shows assigned IPs

## 📂 Files Included
- Packet Tracer file (.pkt)
- Configuration screenshots (optional)

## 🚀 How to Run
1. Open the `.pkt` file using Cisco Packet Tracer
2. Start the simulation
3. Check IP assignment on client PCs
4. Test connectivity using ping
